# 光子学仿真模块设计文档

## 1. 项目背景与目标

### 1.1 背景
OpenHC项目是一个异构计算平台，旨在提供统一的编程语言和工具链，支持代码自动映射到GPU、NPU、FPGA等异构设备。项目已具备基础的异构计算能力，包括编译器、中间表示、构建系统和IDE。

### 1.2 目标
在OpenHC基础上开发类似ANSYS Lumerical功能的光子学仿真模块，实现：
- 光子学特定语法扩展
- 多种光学求解器支持
- 异构设备加速优化
- 完整的可视化与分析工具链

## 2. ANSYS Lumerical功能分析

### 2.1 核心功能
1. **FDTD（时域有限差分）**：时域电磁场仿真
2. **FDE（有限差分本征模）**：波导模式分析
3. **RCWA（严格耦合波分析）**：周期性结构分析
4. **光线追迹**：几何光学分析
5. **材料库**：光学材料参数数据库
6. **参数扫描与优化**：自动化设计优化

### 2.2 技术特点
- 多物理场耦合
- 大规模并行计算
- GPU加速支持
- 参数化设计
- 脚本化自动化

在现有HSCLang基础上添加光子学特定语法：

```rust
// 光子学仿真任务定义
photonics_simulation OpticalSimulation {
    // 仿真域定义
    domain: OpticalDomain {
        size: [1.0, 1.0, 0.5],  // 微米单位
        mesh: [256, 256, 128],  // 网格分辨率
        boundary: PML(8),       // 完美匹配层边界
    },
    
    // 材料定义
    materials: [
        Material {
            name: "SiO2",
            refractive_index: 1.45,
            dispersion: Sellmeier([0.696, 0.408, 0.897, 0.069, 0.116, 9.896]),
        },
        Material {
            name: "Si",
            refractive_index: 3.48,
            dispersion: Polynomial([3.48, -0.001, 1e-6]),
        },
    ],
    
    // 光源定义
    sources: [
        GaussianSource {
            center: [0.5, 0.5, 0.0],
            wavelength: 1.55,  // 微米
            width: 0.1,
            polarization: TE,
        },
    ],
    
    // 监视器定义
    monitors: [
        FieldMonitor {
            name: "field_xy",
            plane: XY,
            position: 0.25,
            frequency_points: 100,
        },
        SpectrumMonitor {
            name: "transmission",
            position: [0.5, 0.5, 0.5],
            frequency_range: [1.2, 1.8],
        },
    ],
    
    // 求解器配置
    solver: FDTDSolver {
        time_steps: 10000,
        courant_factor: 0.99,
        auto_shutoff: 1e-5,
    },
    
    // 计算体
    body() -> SimulationResults {
        // 初始化场
        let fields = initialize_fields();
        
        // 时间步进循环
        for step in 0..solver.time_steps {
            // 更新电场
            update_e_field(fields.e, fields.h);
            
            // 应用光源
            apply_sources(fields.e, step);
            
            // 更新磁场
            update_h_field(fields.h, fields.e);
            
            // 应用边界条件
            apply_boundary_conditions(fields);
            
            // 记录监视器数据
            if step % 100 == 0 {
                record_monitors(fields, step);
            }
            
            // 检查收敛
            if check_convergence(fields) {
                break;
            }
        }
        
        // 后处理
        let results = postprocess(fields);
        results
    }
}
```

// FPGA HLS代码生成
class FPGABackend : public Backend {
public:
    std::string generateHLSCode(const Operation* op) override {
        // 生成带HLS pragma的C++代码
        if (auto* fdtd_op = dyn_cast<FDTDUpdateEOp>(op)) {
            return generateFDTDKernel(fdtd_op);
        }
        // ...
    }
    
private:
    std::string generateFDTDKernel(const FDTDUpdateEOp* op) {
        return R"(
#pragma HLS INTERFACE ap_fifo port=e_field
#pragma HLS INTERFACE ap_fifo port=h_field
#pragma HLS PIPELINE II=1
        
void fdtd_update_e_kernel(
    complex<double> e_field[][][],
    complex<double> h_field[][][],
    double material[][][],
    double dt,
    double dx
) {
    #pragma HLS ARRAY_PARTITION variable=e_field cyclic factor=8 dim=3
    #pragma HLS ARRAY_PARTITION variable=h_field cyclic factor=8 dim=3
    
    for (int i = 1; i < NX-1; i++) {
        for (int j = 1; j < NY-1; j++) {
            for (int k = 1; k < NZ-1; k++) {
                #pragma HLS UNROLL factor=4
                double curl_h = (h_field[i][j+1][k].z - h_field[i][j-1][k].z) / (2*dy)
                              - (h_field[i][j][k+1].y - h_field[i][j][k-1].y) / (2*dz);
                e_field[i][j][k].x += dt / (epsilon0 * material[i][j][k]) * curl_h;
            }
        }
    }
}
        )";
    }
};
```

pub struct FDTDSolver {
    // 场数据
    e_field: FieldData,
    h_field: FieldData,
    
    // 材料数据
    epsilon: MaterialData,
    mu: MaterialData,
    
    // 源数据
    sources: Vec<Source>,
    
    // 监视器
    monitors: Vec<Monitor>,
    
    // 配置参数
    config: FDTDConfig,
}

impl FDTDSolver {
    pub fn new(domain: &OpticalDomain, materials: &[Material]) -> Self {
        // 初始化求解器
    }
    
    pub fn run(&mut self, steps: usize) -> Result<SimulationResults> {
        for step in 0..steps {
            // 更新电场
            self.update_e_field(step);
            
            // 应用光源
            self.apply_sources(step);
            
            // 更新磁场
            self.update_h_field(step);
            
            // 应用边界条件
            self.apply_boundary_conditions();
            
            // 记录监视器数据
            if step % self.config.record_interval == 0 {
                self.record_monitors(step);
            }
            
            // 检查收敛
            if self.check_convergence() {
                break;
            }
        }
        
        self.get_results()
    }
    
    fn update_e_field(&mut self, step: usize) {
        // 根据设备类型选择实现
        match self.config.device {
            Device::GPU => self.update_e_field_gpu(step),
            Device::NPU => self.update_e_field_npu(step),
            Device::FPGA => self.update_e_field_fpga(step),
            Device::CPU => self.update_e_field_cpu(step),
        }
    }
}
```

## 5. 关键技术挑战与解决方案

### 5.1 技术挑战

1. **大规模并行计算**：
   - 挑战：光子学仿真通常需要处理数百万到数十亿网格点
   - 解决方案：利用GPU的大规模并行能力，优化内存访问模式

2. **数值稳定性**：
   - 挑战：FDTD算法需要满足CFL稳定性条件
   - 解决方案：自适应时间步长，稳定性监测与调整

3. **内存消耗**：
   - 挑战：三维场数据内存占用巨大
   - 解决方案：分块计算，内存复用，out-of-core计算

4. **异构设备协同**：
   - 挑战：不同设备间的数据迁移和同步
   - 解决方案：统一内存管理，异步数据传输，任务依赖分析

### 5.2 创新点

1. **统一的异构编程模型**：
   - 利用OpenHC的单一来源多设备生成理念
   - 自动将光子学仿真任务映射到最优设备

2. **AI增强的仿真**：
   - 使用NPU加速近似计算
   - 神经网络替代部分数值计算

3. **实时交互式仿真**：
   - FPGA提供低延迟实时处理
   - 支持设计参数实时调整

4. **开源与可扩展**：
   - 完全开源，社区驱动
   - 模块化架构，易于扩展
